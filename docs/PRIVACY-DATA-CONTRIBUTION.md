# Vesti 隐私说明与数据贡献协议

版本：v1.0 · 生效日期：2026-08-14

亲爱的 Vesti 用户：

感谢你使用 Vesti。在你注册并领取免费会员（Beta 版三个月会员）之前，请仔细阅读本协议。本协议说明我们在你**主动同意**的前提下收集哪些数据、不收集哪些数据、数据用途以及你如何随时退出。**勾选同意即表示你已阅读并接受本协议；不同意则无法领取免费会员，但你仍可阅读本协议后随时改变主意。**

## 一、我们收集什么

在你同意本协议后，Vesti 桌面应用会持续将以下数据上传至我们的服务器：

- 来自本地 AI 编程工具（Kimi Code、Claude Code、Codex、Cursor 等 CLI 与桌面 Agent）的**对话记录**，包括：你与 AI 的消息正文、AI 的思考与回复、工具调用摘要（工具名、输入输出摘要）、对话中涉及的**文件路径**、时间戳、Token 用量与模型信息。

这些数据是 AI Agent 工程研究（包括强化学习训练数据）的宝贵资源，将用于改进 Vesti 产品以及人工智能模型的训练与研究。

## 二、我们不收集什么

- **浏览器端对话**：你在浏览器里与 Kimi、DeepSeek、ChatGPT、Claude、Gemini 等网页 AI 的对话由 Vesti 浏览器扩展捕获，**仅存储在你本地，永远不会被上传**。
- **含个人信息的会话**：上传前，每条会话会经过自动检测；凡内容中命中手机号、电子邮箱、身份证号、银行卡号、私钥/API 密钥等个人信息或敏感凭据模式的会话，**整条会话会被排除，不会上传**。
- **你的账号密码**：用户名与密码仅以加密形式存储在你自己的电脑上，永远不会离开你的设备。

## 三、匿名性

上传数据通过一个随机生成的**匿名贡献者 ID** 标识，与你的用户名无关。服务器端不记录你的 IP 画像，仅做基本的频率限制。

## 四、数据存储与安全

数据存储于我们自有的服务器（阿里云，中国境内），访问权限仅限于核心开发团队，不会出售或共享给任何第三方。

## 五、你的权利与退出

- **随时撤回**：在「设置 → 会员与账号 → 数据贡献」中一键关闭。关闭后立即停止一切上传，本地待上传队列即时清空，不影响你的会员权益。
- **删除请求**：如需删除已上传的数据，请联系我们并提供你的匿名贡献者 ID（设置页可复制），我们将在核实后删除对应数据。
- 本协议变更时，我们会要求你重新阅读并确认。

## 六、风险提示

个人信息过滤基于自动模式检测，尽管我们持续改进检测能力，仍可能存在漏检。**请避免在与 AI 的对话中输入你的真实姓名、住址、证件号码等敏感个人信息。**

## 七、联系我们

如对数据收集有任何疑问，可通过 Vesti GitHub 仓库（github.com/221250144/VESTI-APP）提交 Issue 与我们联系。
